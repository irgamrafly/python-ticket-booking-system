# Python Ticket Booking System

## Description
This project is a simple ticket booking program developed using Python. It applies nested conditional statements to validate visitor requirements, select ticket facilities, calculate food prices, and determine the total payment.

## Features
- Age validation (minimum 12 years old).
- Height validation (minimum 150 cm).
- VIP and Regular ticket selection.
- Food selection (Popcorn or Candy).
- Automatic total payment calculation.

## Technologies
- Python 3
- Conditional Statements (if, elif, else)
- User Input and Output

## How to Run
1. Make sure Python is installed on your computer.
2. Open the terminal in the project directory.
3. Run the following command:

```bash
python ticket_booking.py
```
